How the Model Works

Features · char n-grams (2–5) → 16,384-dim hashed vector, L2-normalized
Heads · MultiOutputClassifier wrapping one LogisticRegression per task
Balance · class_weight="balanced" for rare toxic / non-approved cases
Solver · liblinear · max_iter 2000 · seed 42
Output · clintox_test_predictions.csv (297 × 7)

Both task heads share the identical feature matrix — the multitask requirement — while each learns its own decision boundary. HashingVectorizer is stateless, so no fitting on the test split is possible.
