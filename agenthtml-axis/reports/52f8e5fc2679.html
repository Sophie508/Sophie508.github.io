1 What the task actually asks

Column A is unsorted and repeats. Column B is the version. The same pair can reappear non-adjacently — RP-1 / 1 sits at row 4 and again at row 8. A row's number is its ordinal within its own pair, counted over rows 2 through itself.

So the sheet is not asking for a rank or a unique ID. It is asking for a running tally keyed on two columns at once — and the tally for a row depends on every row above it, which is what makes a fixed full-column formula the wrong shape.

Why the pair splits the count

RP-1 / 1 appears twice — rows 4 and 8 — so those cells read 01 and 02. RP-2 / 2 fills three rows: 01, 02, 03. The same report number at a different version is a different counter. Row 8's 02 is only correct because row 4 already consumed the 01.

2 The formula, opened up

Every answer cell carries the same shape, with only the end of each range moving. Row 5's version, annotated:

=TEXT(COUNTIFS($A$2:A5,A5,$B$2:B5,B5),"00")
The core. Count rows where column A equals this row's A and column B equals this row's B — restricted to the window that ends here.
$A$2:A5  $B$2:B5
The start is absolute, the end is relative. $A$2/$B$2 never move, so the window always begins at the first data row; A5/B5 move with the row, so the window grows as the formula is copied down.
A5 , B5
What is being matched. The pair on the current row — RP-2 and 2. This is the key the tally is grouped by.
TEXT( …, "00" )
Zero padding. Forces two digits so the count reads 01 rather than 1, as the task asked for a number "starting from 01". The stored result is therefore text, not a number.
=COUNTIFS(A:A,A5,B:B,B5)
The near-miss this avoids. Counting the whole columns returns the pair's final total — 03 on every RP-2 / 2 row and 02 on both RP-1 / 1 rows. It cannot distinguish first appearance from last, which is exactly the distinction the task needs.

One consequence of anchoring at row 2 rather than at the sheet's top: the window is insensitive to where the data block starts, but the anchor would need moving if rows were ever inserted above row 2.

from openpyxl import load_workbook

INPUT_PATH  = "/…/01_task_47484/workspace/input.xlsx"
OUTPUT_PATH = "/…/01_task_47484/workspace/output.xlsx"

wb = load_workbook(INPUT_PATH)
ws = wb["Sheet1"]

for row in range(2, 9):
    ws.cell(row=row, column=3).value = (
        f'=TEXT(COUNTIFS($A$2:A{row},A{row},$B$2:B{row},B{row}),"00")'
    )

wb.calculation.fullCalcOnLoad = True
wb.calculation.forceFullCalc  = True
wb.calculation.calcMode       = "auto"
wb.save(OUTPUT_PATH)

# openpyxl does not calculate formulas, so derive and print their expected results.
counts = {}
for row in range(2, 9):
    key = (ws.cell(row, 1).value, ws.cell(row, 2).value)
    counts[key] = counts.get(key, 0) + 1
    print(f"C{row}={counts[key]:02d}")
