Open criteria
FAQ

Case questions, answered.

What is this HTML presenting?
A self-contained product-style prototype of ClawBench case 05_022-daily-life-transportation-turo-enterprise: an autonomous agent attempted to book a same-day compact rental under a browser-only constraint, and the run is summarized for review.
Did the agent finish the booking?
No. interception.json records pass: false with stop reason time_limit_exceeded. The success interceptor (Turo search GET) never triggered.
Why was Turo expected?
Case metadata lists sites_involved: turo.com and platform turo-enterprise. The eval schema only accepts a Turo search URL with daily duration parameters.
Where are screenshots or raw requests?
This case package has no local screenshots directory. Oversized raw request traffic is referenced only as data/requests.jsonl (≈6.2 MB beyond the embed size cap). Trajectory steps are reconstructed from agent messages and the actions log.
What times and year did the UI calendar use?
During the run the Kayak calendar showed April–June 2026; the agent advanced to June and selected the 20th for both legs, aligning with a future-dated day-trip booking relative to the March 27, 2026 session timestamp.
