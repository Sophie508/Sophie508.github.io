Before · E1 array formula

Stored as an array formula (t="array" ref="E1"). Scans relative columns, takes the max position among non-zeros, then indexes that position — heavy for the job.

After · E1 shortened

=LOOKUP(2,1/(B6:H6<>0),B6:H6)
Classic last-match trick: divide 1 by the boolean mask, LOOKUP seeks 2 past every 1, and falls back to the final numeric hit — no CSE array entry required for this pattern.

05 · Delivered solution

What landed in output.xlsx and solve.py

E1 final write
=LOOKUP(2,1/(B6:H6<>0),B6:H6)
  1. B6:H6<>0 builds a truth mask over the week’s quotas.
  2. 1/mask yields 1s for live days and #DIV/0! for zeros (ignored by LOOKUP).
  3. Lookup value 2 is larger than any 1, so Excel settles on the last successful match — Monday’s 1008.33….
exit code 0 34.8 seconds openpyxl write verified readback
solve.py
from openpyxl import load_workbook

INPUT_PATH = ".../workspace/input.xlsx"
OUTPUT_PATH = ".../workspace/output.xlsx"

wb = load_workbook(INPUT_PATH)
ws = wb["Sheet1"]

# Return the last non-zero daily quota from B6:H6
# without an array-entered formula.
ws["E1"] = "=LOOKUP(2,1/(B6:H6<>0),B6:H6)"

wb.save(OUTPUT_PATH)
print(f"E1={ws['E1'].value}")
