The assignment

Continuous inhibition, reframed as a binary decision.

The DKPES dataset records a continuous Signal-inhibition value per compound. The task binarizes it at the training-set median, then asks a Random Forest to separate strong inhibitors from weak ones using shape and chemistry descriptors alone.

⚖

Median threshold

The training median of Signal-inhibition sets the class boundary. Values ≥ median become class 1 (inhibitor); the same cutoff labels the test set.

🌲

Ensemble of trees

A RandomForestClassifier with 200 estimators and a fixed seed learns non-linear interactions among the descriptors without feature scaling.

📊

Honest evaluation

Accuracy, ROC-AUC, a full classification report and confusion matrix on the untouched 50-compound test split — plus feature importances.

"""Random Forest classifier for predicting signal inhibition of chemicals
from their molecular descriptors (DKPES dataset).

The continuous "Signal-inhibition" target is binarized using the median of the
training set as the threshold (values >= median -> 1 "inhibitor", else 0)."""

import os
import numpy as np
import pandas as pd
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import (accuracy_score, classification_report,
    confusion_matrix, roc_auc_score)

HERE = os.path.dirname(os.path.abspath(__file__))
TRAIN_PATH = os.path.join(HERE, "dkpes", "dkpes_train.csv")
TEST_PATH  = os.path.join(HERE, "dkpes", "dkpes_test.csv")
PRED_PATH  = os.path.join(HERE, "dkpes_test_predictions.csv")

TARGET = "Signal-inhibition"
ID_COL = "index"
FEATURES = ["3-Keto", "3-Hydroxy", "12-Keto", "12-Hydroxy",
    "19-Methyl", "18-Methyl", "Sulfate-Ester", "Sulfate-Oxygens",
    "C4-C5-DB", "C6-C7-DB", "Sulfur", "TanimotoCombo",
    "ShapeTanimoto", "ColorTanimoto", "Overlap"]
RANDOM_STATE = 42

def main():
    # 1. Load and explore
    train_df = pd.read_csv(TRAIN_PATH)
    test_df  = pd.read_csv(TEST_PATH)

    # 2. Binarize target using the training-set median
    threshold = train_df[TARGET].median()
    y_train = (train_df[TARGET] >= threshold).astype(int)
    y_test  = (test_df[TARGET]  >= threshold).astype(int)
    X_train, X_test = train_df[FEATURES], test_df[FEATURES]

    # 3. Train Random Forest
    clf = RandomForestClassifier(n_estimators=200, max_depth=None,
        random_state=RANDOM_STATE, n_jobs=-1)
    clf.fit(X_train, y_train)
    importances = pd.Series(clf.feature_importances_,
        index=FEATURES).sort_values(ascending=False)

    # 4. Evaluate on the test set
    y_pred  = clf.predict(X_test)
    y_proba = clf.predict_proba(X_test)[:, 1]
    acc = accuracy_score(y_test, y_pred)
    if y_test.nunique() > 1:
        roc = roc_auc_score(y_test, y_proba)
    print(classification_report(y_test, y_pred, digits=4, zero_division=0))
    print(confusion_matrix(y_test, y_pred))

    # 5. Save predictions
    out = pd.DataFrame({ID_COL: test_df[ID_COL],
        "signal_inhibition_true": test_df[TARGET],
        "y_true": y_test, "y_pred": y_pred, "prob_class1": y_proba})
    out.to_csv(PRED_PATH, index=False)

if __name__ == "__main__":
    main()

Details

Design decisions & caveats.

Why binarize at the median instead of a fixed cutoff? +

The median guarantees a roughly balanced split of the training labels regardless of the target's scale or skew, which keeps the forest from trivially favouring one class. Crucially, the same train-derived threshold is reused on the test set, so no test information leaks into label construction.

Why 200 trees and no feature scaling? +

Random forests are invariant to monotonic feature transforms, so standardizing the descriptors would add nothing. 200 estimators with a fixed random_state=42 trades a little compute for a stable, reproducible importance ranking on only 200 training rows.

Why is ROC-AUC guarded by a class check? +

roc_auc_score is undefined when the test set contains a single class. The script computes it only when y_test.nunique() > 1, so an all-one-class split degrades gracefully to accuracy plus the classification report.

Why did the run stop before training? +

The file write required an approval that was never granted, and the agent's working guideline was to delegate any experiment execution to a subagent rather than run it directly. With the write blocked, it produced a plan and code for review instead of results.
