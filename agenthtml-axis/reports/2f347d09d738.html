02 Paper Overview

Abstract

While large language models (LLMs) have rapidly improved their performance on a broad number of tasks, they still often fall short on reasoning tasks. As LLMs become more integrated in diverse real-world tasks, advancing their reasoning capabilities is crucial to their effectiveness in nuanced, complex problems. Wang et al. [33]'s self-consistency framework reveals that sampling multiple rationales before taking a majority vote reliably improves model performance across various closed-answer reasoning tasks. Standard methods based on this framework aggregate the final decisions of these rationales but fail to utilize the semantic information detailed in the step-by-step reasoning paths. Our work introduces semantic self-consistency, enhancing this approach by incorporating and analyzing both the reasoning paths of these rationales in addition to their final decisions before taking a majority vote. These methods not only improve the reliability of reasoning paths but also cause more robust performance on complex reasoning tasks.

Key scoping rules the agent must follow:

Results involving Llama 2 7B, Mistral 7B, and Llama 3 8B are not required for replication. Only results involving gpt-3.5-turbo and gpt-4o-mini are required for replication. Note, gpt-4o-mini is a new OpenAI model that you may not have heard about before, and can be queried using the standard OpenAI API.

For all datasets, the answer is parsed as the string immediately following the string “the answer is ” (being case insensitive), removing any whitespace, fullstops, and parentheses. e.g.
"The answer is 2." -> 2
"The answer is (B)" -> B

For the "top prob" method for all datasets, generations are only considered in metric computation if an answer could be extracted. This is the same for all generations methods for AQuA-RAT; only generations where an answer could be extracted are considered.

The RoBERTA model is RoBERTa base (125 million parameters).

For self-consistency, centroid proximity weighting, and semantic consensus weighting, k=10 responses are generated.

When evaluating gpt-3.5-turbo and gpt-4o-mini:
- A system prompt of "Follow the exact formatting as demonstrated in the examples." is used.
- All examples are passed in one message, rather than in a chat-based conversation.
