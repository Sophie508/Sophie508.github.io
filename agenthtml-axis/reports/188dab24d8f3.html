Site Code Extraction

Parsing Hidden Structure
from Delimited Strings

A formula-based approach to extract embedded site codes from varying-length double-slash delimited text, with automatic numeric type coercion.

01 · Task

The spreadsheet holds business display names structured as //-delimited strings. Each string embeds a site code in a fixed structural position — the 4th segment from the left, or equivalently the segment just before the terminal //US.


Rows 2–3 come pre-filled with the expected results; rows 4–7 are blank. The task requires writing a single reusable formula to B2:B7 that extracts the correct site code. Additionally, the formula must coerce purely numeric codes to integers, dropping leading zeros (as shown by the known B4 example: 00321553 → 321553).

String Structure — Identified Pattern

NAME // CITY // ZIP / PHONE // SITE CODE ← target // COUNTRY
Key insight: the site code is always the 4th segment — equivalently, the segment between the last two // delimiters. The segment widths vary across rows; no fixed character offsets work.
03 · Formula
Excel Formula — written to B2:B7 B2:B7
=LET(
  code,  TEXTBEFORE(TEXTAFTER(A2, "//", -2), "//"),
  IFERROR(VALUE(code), code)
)
Formula Anatomy
1
TEXTAFTER(A2, "//", -2) — the -2 instance counts from the end, returning everything after the 2nd-to-last //. Result: SITE_CODE//US
2
TEXTBEFORE(..., "//") — extracts everything before the first // in that result, isolating SITE_CODE alone.
3
LET(code, ...) — names the intermediate value code so it can be referenced twice without recalculating the nested TEXTAFTER/TEXTBEFORE chain.
4
IFERROR(VALUE(code), code) — attempts numeric conversion; if VALUE() fails (alphanumeric code), falls back to the text value. This produces 321553 from 00321553 and preserves A14827 as text.
