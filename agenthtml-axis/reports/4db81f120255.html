Repair Result

The agent changed the boolean operation handling in cognitive_complexity/utils/ast.py. The previous formula multiplied each nested ast.BoolOp by max(increment_by, 1), which added nesting complexity where the specification says only a fundamental increment applies.

The test suite was updated to reflect the corrected counts for the real-world example and a lambda nesting case.

Issue Statement

Problem: sequences of binary logical operators were counted with both a fundamental increment and a nesting increment.

Expected behavior: according to the Cognitive Complexity specification, boolean operator sequences should receive the B1 fundamental increment only. In the existing test_real_function(), the multiline if condition should count as +2, not +4, making the total complexity 9 instead of 11.

def process_raw_constant(constant, min_word_length):
