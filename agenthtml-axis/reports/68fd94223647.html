Step-by-Step Problem Journey

Step 1 — Problem
Original Problem Statement
Given a5 − a3 + a − 2 = 0, find ⌊a6⌋. (India National Math Olympiad 2003)
Step 2 — Monotonicity
Proving f is Strictly Increasing
Let f(x) = x5 − x3 + x − 2. Then f′(x) = (2x2−1)2 + x2 + x4 ≥ 0, so f is increasing → unique root.
Step 3 — Current State
Bracketing the Root by IVT
f(1) = −1, f(2) = 24 → root in (1,2). Then f(65) = −1243125 < 0, f(54) = 3571024 > 0. So 65 < a < 54.

Where the Student Got Stuck

🎓 Student Question

Insight Identification

Direct Bounds Straddle Both 3 and 4

The crude bounds (65)6 < a6 < (54)6 straddle both 3 and 4, so they cannot determine ⌊a6⌋ alone.

The key: the defining equation itself provides an algebraic expression for a6 in terms of lower powers of a, giving access to much tighter bounds.
📄
Operation Prescription

Multiply the Equation by a

Multiply a5 − a3 + a − 2 = 0 by a, then rearrange to isolate a6:

a6 = a4 − a2 + 2a

Define g(x) = x4 − x2 + 2x, which is also monotone increasing on (65,54). Evaluate g at the endpoints to bound a6.
✅
Operation Execution

Compute and Conclude

g′(x) = 4x3 − 2x + 2 > 0, so g is increasing. Then:

g(65) = 1896625 > 3

g(54) = 865256 < 4

Therefore 3 < a6 < 4, so ⌊a6⌋ = 3.
Final Answer
⌊a6⌋ = 3
Because 3 < a6 < 4, the floor is exactly 3.

Solution Strategy

Four Logical Moves

The complete solution transforms a polynomial constraint into a definitive floor value in four clean steps.

1

Prove Uniqueness

Show f′(x) = (2x2−1)2 + x2 + x4 ≥ 0, so f is strictly increasing, guaranteeing exactly one real root.

2

Bracket with IVT

Evaluate f at 65 (negative) and 54 (positive). By IVT, 65 < a < 54.

3

Exploit the Equation

Multiply by a to get a6 = a4 − a2 + 2a. This converts the problem to bounding the polynomial g(a).

4

Apply Monotonicity Again

Since g′(x) > 0 on the interval, g(65) > 3 and g(54) < 4, giving ⌊a6⌋ = 3.

Clarifications

Common Questions

Why can’t we just raise the bracket bounds to the 6th power?
Raising the bounds gives (65)6 = 4665615625 ≈ 2.986 and (54)6 = 156254096 ≈ 3.815. The lower bound is just under 3 and the upper bound is just under 4, so the interval spans across integer 3. We cannot tell whether ⌊a6⌋ = 2 or 3 from these alone.
Where does a6 = a4 − a2 + 2a come from?
From the defining equation: rearrange to a5 − a3 + a = 2, then multiply both sides by a: a6 − a4 + a2 = 2a. Rearranging: a6 = a4 − a2 + 2a.
How is g′(x) = 4x3 − 2x + 2 > 0 justified on the interval?
At the left endpoint x = 6/5 = 1.2: 4(1.2)3 − 2(1.2) + 2 = 6.912 − 2.4 + 2 = 6.512 > 0. More rigorously, for x ≥ 1: 2x3 − x = x(2x2 − 1) ≥ 0, so g′(x) = 2(2x3 − x + 1) ≥ 2 > 0.
