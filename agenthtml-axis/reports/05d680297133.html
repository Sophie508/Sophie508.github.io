Python code
import sqlite3, duckdb, pandas as pd

# Load exchange info
info = pd.read_sql_query(
    "SELECT rowid AS id, Exchange, Currency FROM index_info",
    sqlite3.connect("data/indexInfo_query.db")
)

# Load all trade data
trades = duckdb.connect("data/indextrade_query.db", read_only=True) \
               .execute("SELECT * FROM index_trade").df()

# Map rowid → ticker (same positional order used in the database)
index_order = ["NYA","IXIC","HSI","000001.SS","N225","N100",
               "399001.SZ","GSPTSE","NSEI","GDAXI","KS11","SSMI","TWII","J203.JO"]
info["Index"] = index_order

# Keep only North American exchanges
north = info[info.Exchange.str.contains("New York|NASDAQ|Toronto")][["Index","Exchange"]]

# Join, filter to 2018
x = trades.merge(north, on="Index")
x["parsed_date"] = pd.to_datetime(x["Date"], format="mixed")
x = x[x.parsed_date.dt.year.eq(2018)]

# Classify each day: up = Close > Open
x["day"] = x["Close"].sub(x["Open"]).map(
    lambda v: "up" if v > 0 else ("down" if v < 0 else "flat")
)

# Aggregate
ans = (x.groupby(["Index","Exchange","day"]).size()
         .unstack(fill_value=0).reset_index())
ans["more_up_than_down"] = ans["up"] > ans["down"]
print(ans.to_string(index=False))
print("\nANSWER:", ", ".join(ans.loc[ans.more_up_than_down, "Index"]))

Final Answer

Using Close > Open to define an up day and Close < Open to define a down day, only IXIC (NASDAQ Composite) had more up days than down days in 2018, with 131 up days vs 120 down days. NYA (NYSE) and GSPTSE (TSX) both had more down days than up days.

Methodology
Up day: Close > Open (positive intraday return) Down day: Close < Open (negative intraday return) Flat day: Close = Open (GSPTSE had 1 flat day) North American exchanges matched by substring search on the Exchange column: "New York" → NYA (NYSE Composite) "NASDAQ" → IXIC (NASDAQ Composite) "Toronto" → GSPTSE (S&P/TSX Composite) Dates parsed with pandas mixed-format parser. Year filter: parsed_date.year == 2018. Total 2018 records: 251 (IXIC) + 251 (NYA) + 251 (GSPTSE).
