The defense

A sanitizer built on BeautifulSoup

The 960-byte /app/filter.py parses the document, then aggressively deletes anything that looks like a script surface. On paper, it removes every classic XSS entry point.

</>

Kills script tags

Every <script> element is dropped via soup("script") — regardless of its type attribute.

▤

Kills framing tags

Blacklists <frame>, <iframe>, <object> and <embed>, closing off nested-document vectors.

on*

Kills event handlers

Iterates every tag and deletes any attribute whose name startswith("on") — onclick, onerror, onload, all gone.

◎
The blind spot.

The filter only walks real element nodes (find_all(True)). Comment nodes are never inspected — and it never asks whether a browser will parse the re-serialized HTML the same way BeautifulSoup did. That gap between two parsers is the whole game.

The attack

Eighteen tries down one rabbit hole

Each payload was written to out.html, run through the real filter, and inspected. Two failure modes recur: the filter eats the vector, or the vector survives but the browser refuses to execute it. Expand any step to see the exact payload.

The solution

Comment breakout: <!--> is an empty comment

The winning file hides a live <img onerror> inside what BeautifulSoup treats as one big comment — but which the browser splits apart at <!-->.

✓ Alert fired after filtering — challenge solved
<!--><img src=x onerror="alert('XSS Bypass!')">-->

FILTER SEES one inert comment

  1. BeautifulSoup parses <!-->...--> as a single comment node spanning the <img>.
  2. The sanitizer only iterates real tags with find_all(True) — comment nodes are skipped entirely.
  3. No script tag, no on* attribute is ever visible to the deletion loop. Nothing gets removed.

BROWSER SEES a live image

  1. Per the HTML spec, <!--> is an abruptly-closed empty comment — it ends immediately.
  2. The following <img src=x onerror=...> is now real markup, not comment text.
  3. src=x fails to load → the surviving onerror handler runs → alert() fires automatically. No click needed.
