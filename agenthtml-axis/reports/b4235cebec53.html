Self-Consistency.

Tim Knappe, Ryan Li, Ayush Chauhan, Kaylee Chhua, Kevin Zhu, Sean O'Brien
ALGOVERSE AI RESEARCH — cs.timknappe@gmail.com · kevin@algoverse.us

Self-consistency samples many reasoning paths and takes a majority vote on the final answer — but discards the semantics of how each path reasoned. This paper reranks the vote by embedding each rationale and weighting answers by the geometry of those embeddings: which answers cluster, which sit near the centroid, and which paths agree with one another.

02

The four mechanisms

from the paper, §4–§5
Baseline

Self-consistency

Sample k=10 chain-of-thought rationales at temperature 0.8, extract each final answer, take the modal answer. The thing every other method is measured against.

answer = argmaxa Σ 𝟙[final_answer(pathi) = a]
§4.1.1

Centroid Proximity Weighting

Embed each full reasoning path. Compute the centroid, distance each path from it, and weight inversely to (normalised) distance. Tight clusters near the middle dominate.

centroid =  1⁄N Σ ei
disti = ‖ei − centroid‖
wi = 1 ⁄ (disti ⁄ Σ distj)
answer = argmaxa Σi∈I(a) wi
§4.1.2

Semantic Consensus Weighting

Score each path by its summed cosine similarity to every other path; aggregate those scores by answer. Coherent clusters reward one another, scattered votes deflate.

sim(ea,eb) = ea·eb ⁄ (‖ea‖‖eb‖)
Si = Σj sim(ei,ej)
answer = argmaxa Σi∈I(a) Si
§4.2

Outlier removal

A filtering pass that discards degenerate or hallucinated rationales before voting, rather than reranking. Three detectors, tuned per Appendix I.2.

k-NN ‖x−y‖₂
Isolation forest s(x,n)=2^(−E[h(x)]⁄c(n))
One-class SVM ½ωᵀω + C Σ ζi
