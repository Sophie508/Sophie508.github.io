01The Problem restored from task registry · original instruction lost in recording

Two confidence metrics

KL(P‖U) = Σ P(i)·log( P(i) / U(i) )
forward — model vs. uniform
KL(U‖P) = Σ U(i)·log( U(i) / P(i) )
backward — uniform vs. model

Higher KL from uniform ⇒ higher predicted confidence. The task asks for a distribution that pins both divergences to the same value at once.

Exact targets

  • forward  KL(P‖U)= 10.0
  • backward KL(U‖P)= 10.0
  • tolerance (both)|KL − 10| ≤ 0.001
  • vocabulary size n150,000
  • constraintvalid P, Σ = 1
  • deliverable/app/dist.npy
the agent's key insight
KL(U‖P) = log(n) − Σ (1/n)·log P(i) = log(n) + H(P)/n
forward KL couples to entropy: KL(P‖U) = log(n) − H(P), with log(150000) ≈ 11.918
// a coupled non-linear system — the two divergences pull the distribution in opposite directions, which is exactly what made the numerical search expensive.
