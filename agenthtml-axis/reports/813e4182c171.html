Problem statement

The library was overcounting sequences of binary logical operators. The Cognitive Complexity specification gives those sequences a fundamental increment, but not the extra nesting increment.

The reported example expected process_raw_constant() to score 9, not 11. The multiline if condition had been treated as +4; it should be +2.

def process_raw_constant(constant, min_word_length):
    processed_words = []
    raw_camelcase_words = []
    for raw_word in re.findall(r'[a-z]+', constant):  # +1
        word = raw_word.strip()

            len(word) >= min_word_length

        ):
            if is_camel_case_word(word):  # +2

            else:  # +1
