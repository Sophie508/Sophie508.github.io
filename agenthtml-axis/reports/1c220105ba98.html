The Challenge

Extract a code buried in varying text

Each row in column A encodes a company name, city, ZIP, site code, and country as //-delimited segments. The site code is always the penultimate segment — but strings differ in length and the code itself can be numeric or alphanumeric.

String anatomy
HONEG BUCKET FLOHAWK//PUYALLUP//98373//103137391INACT//US
Company name // City // ZIP // Site Code ← target // Country

The Formula

One formula, all cases

Uses modern Excel functions to navigate from the right, extract the penultimate segment, and coerce numeric codes to numbers.

Excel Formula · B2:B7
=LET(code, TEXTBEFORE(TEXTAFTER(A2, "//", -2), "//"), IFERROR(VALUE(code), code))
TEXTAFTER(A2, "//", -2)

Returns everything after the 2nd-to-last occurrence of //. Negative instance counts from the right.

TEXTBEFORE(…, "//")

Takes the result above and returns everything before the first // — isolating just the site code segment.

LET(code, …)

Names the intermediate result code so it's computed only once and the expression stays readable.

IFERROR(VALUE(code), code)

Converts purely-numeric codes to numbers (e.g. 321553); if VALUE fails (alphanumeric), returns the text as-is.

Python · solve.py
from pathlib import Path from openpyxl import load_workbook INPUT = Path("/…/workspace/input.xlsx") OUTPUT = Path("/…/workspace/output.xlsx") workbook = load_workbook(INPUT) sheet = workbook["Sheet1"] # site code = segment between last two // delimiters # IFERROR(VALUE(...)) coerces numeric-only codes to numbers for row in range(2, 8): sheet.cell(row, 2).value = ( f'=LET(code,TEXTBEFORE(TEXTAFTER(A{row},"//", -2),"//"),' f'IFERROR(VALUE(code),code))' ) workbook.calculation.fullCalcOnLoad = True workbook.calculation.forceFullCalc = True workbook.calculation.calcMode = "auto" workbook.save(OUTPUT) for row in range(2, 8): print(f"B{row}={sheet.cell(row, 2).value}")
