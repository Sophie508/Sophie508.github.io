Features

Built for messy warehouse codes

Partial tokens, broken external links, and cross-sheet tables — the same failure modes that ship-stop sales workbooks.

🔗

Hyphen-bounded match

Surrounds each size code with dashes so 750 only matches -750-, never a longer SKU fragment.

📐

LOOKUP array trick

Uses LOOKUP(2,1/(ISNUMBER(SEARCH(...)))) to return the last successful position without helper columns.

📑

Cross-sheet ready

Prefix ranges with Sheet2! when the partial-SKU map lives on another worksheet — same formula shape.

🚫

#REF! recovery

Replaces brittle external workbook VLOOKUPs that point at missing Table3 links with a local self-contained formula.

🐍

openpyxl delivery

Agent wrote solve.py, loaded input.xlsx, set F8, and saved output.xlsx.

Why VLOOKUP failed

Root cause

Exact match against full code

Original formula looked up entire E8 inside an external Table3. Codes are compound — only the middle size token lives in the map.

Broken external path

C:/Users/jesse/Desktop/…xlsx!Table3 resolved to #REF! in this workbook.

SEARCH is a function

Not “-search”. Concatenating "-"&code&"-" turns 750 into the needle -750-.

Off-sheet adjustment

Qualify ranges: Sheet2!$A$8:$A$18 and Sheet2!$B$8:$B$18.

FAQ

Formula questions from the prompt

Answers grounded in the agent’s final explanation.

What formula solves Sheet1!F8? 
=LOOKUP(2,1/(ISNUMBER(SEARCH("-"&$A$8:$A$18&"-",E8))),$B$8:$B$18)
For E8 = FG:LA-750-00506 the result is 750ml.
Is “-search” a separate formula?
No. SEARCH is a standard Excel function. The leading dash is a string literal concatenated around each partial SKU so the needle becomes -750-, which only hits the dashed size segment inside the full code.
How does LOOKUP(2, 1/(…)) work here?
ISNUMBER(SEARCH(...)) yields TRUE/FALSE for each row. Dividing 1 by that array produces 1s and #DIV/0! errors. LOOKUP seeks 2, walks past every 1, and returns the corresponding value from B8:B18 for the last numeric match — classic “last match” array pattern for older Excel.
What if the map is on another worksheet?
Qualify both ranges: 
=LOOKUP(2,1/(ISNUMBER(SEARCH("-"&Sheet2!$A$8:$A$18&"-",E8))),Sheet2!$B$8:$B$18)
Why not stay with VLOOKUP?
VLOOKUP needs an exact key. The full code is not in column A — only the size fragment is. The prior formula also referenced a missing external Table3 path, which surfaced as #REF!.
What files did the agent produce?
workspace/solve.py and workspace/output.xlsx with F8 set. Input workbook remains workspace/input.xlsx. Trajectory format: codex-jsonl. References list is empty for this case.
