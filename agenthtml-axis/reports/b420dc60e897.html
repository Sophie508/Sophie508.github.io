2 Task statement

Given a weekly textiles sales / quota workbook, the user wants a shorter formula for cell E1. That cell should return the most recent non-zero “daily quota to date” from row 6 (B6:H6). The user’s previous (wrong / too long) answer was an array formula: 

=INDEX($B$6:$H$6,,MAX(IF($B$6:$H$6<>0,COLUMN($B$6:$H$6)-COLUMN($B$6)+1)))
Prompt note: the long formula is described as “related to the formula in cell E1” and the wrong-answer text is exactly that INDEX/MAX/IF expression. The agent must load input.xlsx, write the corrected formula into E1, save output.xlsx, and print the written value.

4 Solution approach

Long / wrong array formula (input E1)
=INDEX($B$6:$H$6,,MAX(IF($B$6:$H$6<>0,
  COLUMN($B$6:$H$6)-COLUMN($B$6)+1)))

Builds relative column indexes where the range is non-zero, takes MAX (rightmost hit), then INDEX. Requires array entry in older Excel; verbose.

Shortened formula written by agent
=LOOKUP(2,1/(B6:H6<>0),B6:H6)

Classic last-match trick: 1/(range<>0) is 1 or #DIV/0!; LOOKUP seeks 2 and returns the last numeric 1’s corresponding value from B6:H6. No CSE array needed.

Why this matches the task

  • Looks only at B6:H6 — same domain as the long formula.
  • Returns the last non-zero daily quota (evaluated prompt value ≈ 1008.333…).
  • Materially shorter and more idiomatic than INDEX + MAX + IF + COLUMN arithmetic.
