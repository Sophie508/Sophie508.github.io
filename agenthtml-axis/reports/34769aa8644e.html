FAQ

Questions about this prototype

What is the user trying to accomplish?

Locate personal trainers on Thumbtack who preferably identify as female, suitable for a 37-year-old client, in ZIP code 07055 (Passaic, NJ area).

Why is the age filter 31–40 instead of exactly 37?

Thumbtack’s booking filters expose age bands. The human annotator mapped age 37 onto the radio option “31 - 40 years old,” which is the only exposed bucket containing 37.

What do the final “circle” clicks mean?

In the captured DOM, preference radios render as circular controls. The trajectory encodes those targets generically as [circle]. Context from checked state and task text identifies them as client age, then female preference.

Is this a live Thumbtack integration?

No. This is a self-contained HTML prototype that reconstructs the flow and marketplace snapshot from the Mind2Web trajectory for presentation and teaching. No external network calls are made.

Which benchmark produced this case?

Mind2Web (upstream). Domain: web_navigation / Service / Home service. Trajectory format: mind2web-json. Model field: human-annotator.
