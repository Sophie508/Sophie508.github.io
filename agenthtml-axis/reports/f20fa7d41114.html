Core Capabilities

Architected for True Foundation Model Robustness

Traditional adversarial training breaks zero-shot generalization and causes catastrophic hallucination. FARE solves this by aligning the feature manifold without supervision.

Unsupervised Feature Adversarial Fine-Tuning

FARE minimizes the squared Euclidean distance between the perturbed student vision embedding and the clean teacher embedding: max||z-x||≤ε ||φFT(z) - φOrg(x)||2. No class labels or paired captions are required.

Frequently Asked Questions

Deep Technical Clarifications

Insights into the mechanics of unsupervised adversarial fine-tuning and the PaperBench reproduction guidelines.

Why does unsupervised fine-tuning (FARE) beat supervised adversarial training (TeCoA)?
Supervised adversarial training (TeCoA) uses class labels via cross-entropy loss, which forces the model to prioritize only discriminative features needed to separate classes under perturbation. This warps the feature space, destroying fine-grained semantic grounding, causing catastrophic object hallucination in VLMs (POPE drops to 72.2%), and impairing zero-shot transfer across unseen datasets. In contrast, FARE minimizes feature-space L2 divergence between the perturbed student and clean teacher: max||z-x||≤ε ||φFT(z) − φOrg(x)||2. As proven in Theorem A.1, bounding L2 embedding drift strictly bounds the change in cosine similarity with text embeddings, thereby preserving the holistic multi-modal representations.
How does FARE plug into LLaVA-1.5 without retraining the LLM or projector?
Large Vision-Language Models like LLaVA-1.5 utilize a pre-trained CLIP vision encoder to transform an input image into a sequence of patch embeddings, which are then passed through a linear projection matrix into the language model (Vicuna 7B). Because FARE trains the student vision encoder to match the feature outputs of the original frozen CLIP model, the resulting token geometry remains aligned with the projection matrix. Replacing model.visual with the FARE state dict requires zero gradient steps on the multi-modal projector or the LLM decoder.
What critical addendum clarifications were required for exact reproduction?
The official addendum specifies several non-trivial implementation constraints:
• Precision Dtypes: Half-precision (fp16) attacks must use 16-bit integer labels (torch.int16), whereas single-precision (fp32) attacks must use 32-bit integers (torch.int32).
• Vision Encoder Resolution: LLaVA-1.5 7B was configured with OpenAI CLIP ViT-L/14@224px rather than Hugging Face's default 336px tower, using OpenCLIP directly.
• PGD Specifics: Elementwise sign gradient normalization for L∞, momentum factor of 0.9, uniform random perturbation initialization, and projection bounds calculated around non-normalized [0, 1] inputs.
• VQA Staged Evaluation: Low-precision attacks on the top-5 frequent ground-truth answers, followed by a high-precision attack on the lowest-scoring answer, and targeted attacks with lowercase "maybe" and capitalized "Word" (with "Word" omitted for TextVQA).
• Worst-case CIDEr: Caption scores are recomputed after every attack stage to record the worst-case sample metric.
Why is nominal CLIP 100% susceptible to stealth targeted attacks?
Standard CLIP features are extremely vulnerable to imperceptible ℓ∞ perturbations (ε=2/255 or 4/255). An adversary can compute a gradient directing the visual features of any harmless image (such as a train, nurse, or dog) directly into the embedding coordinates of an attacker-crafted text token sequence (e.g. EmailAPI(...) or Sell your stocks...). Because standard CLIP lacks adversarial feature margins, the perturbed embedding completely overrides the visual content while remaining visually indistinguishable to human eyes.
Does FARE defend against visual jailbreaks (Qi et al. 2023)?
Yes! In Table 7, Qi et al.'s universal targeted visual jailbreak attack attempts to bypass LLaVA-1.5's safety guardrails using 5,000 iterations of sign PGD on a derogatory corpus. At ε=64/255, standard CLIP's defense collapses completely with an 90.0% attack success rate (36/40 harmful prompts executed). In contrast, LLaVA equipped with FARE⁴ resists the attack, reducing the success rate to 57.5% and completely neutralizing existential risk and cybercrime triggers.
