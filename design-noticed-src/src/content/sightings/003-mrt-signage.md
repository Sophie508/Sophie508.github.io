title: MRT Signage
context: Singapore
principles: [Alignment]
sketch: mrt-signage
noticed: Arrows sit in one column, the coloured badges in a second, the words in a third. Every row is built on the same three lines.
why: I read this sign while walking. Because every word starts in the same place, my eye drops straight down the column instead of hunting row by row.
rule: If people read it while moving, give every row the same start.
