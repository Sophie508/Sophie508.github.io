The Assignment

What the agent was asked to build

Prompt delivered to the agent

Analyze and visualize elk movement patterns. Generate synthetic GPS tracking data for multiple elk individuals, then:

  1. Create a dataset of elk GPS positions (longitude, latitude, individual ID, timestamp, habitat indicators)
  2. Estimate home ranges for each individual using convex hull or kernel density
  3. Identify spatial clusters in the movement data using DBSCAN or similar
  4. Assess habitat preferences based on movement patterns
  5. Create a visualization showing movement tracks, home ranges, and clusters
  6. Save the visualization as a PNG file and print summary statistics

Toolchain: Python with pandas, numpy, scikit-learn, and matplotlib.

Methodology note

Habitat is assigned per-fix using a spatially autocorrelated model: forest cover from sinusoidal fields, riparian zones within 450 m of a simulated stream, and grassland as the residual. Each fix carries forest_cover, distance_to_water_m, elevation_m, and a categorical habitat label.

Debugging Iteration

Two patches the agent applied

After the first successful run, the agent noticed a unit error in the speed calculation and a NumPy 2.0 deprecation warning. Both were fixed with a single apply_patch call.

Fix 01 — Speed Unit

Speed was computed as meters/hour instead of km/h. The agent inserted a / 1000 divisor.
- data["speed_kmh"] = data["step_distance_m"] / dt_h
+ data["speed_kmh"] = data["step_distance_m"] / 1000 / dt_h

Fix 02 — NumPy 2.0 Deprecation

np.cross on 2D vectors is deprecated in NumPy 2.0. Replaced with an explicit 2D cross product.
- return float(np.cross(a - o, b - o))
+ oa, ob = a - o, b - o
+ return float(oa[0] * ob[1] - oa[1] * ob[0])
Source Code Highlights

Key algorithms in the script

Correlated random walk

Each elk follows a persistent velocity with attraction to its activity center and a sinusoidal diurnal forage pull.

generate_data()
for t in range(n): phase = 2 * np.pi * (t % fixes_per_day) / fixes_per_day forage_pull = np.array([80 * np.cos(phase + i), 55 * np.sin(phase + i)]) velocity = 0.55 * velocity + 0.055 * (center - pos) + forage_pull velocity += rng.normal(0, 180, 2) pos = pos + velocity xy[t] = pos

Convex hull (Andrew's monotone chain)

A from-scratch 2D convex hull — no SciPy dependency.

convex_hull()
def cross(o, a, b): oa, ob = a - o, b - o return float(oa[0] * ob[1] - oa[1] * ob[0]) lower = [] for p in points: while len(lower) >= 2 and cross(lower[-2], lower[-1], p) <= 0: lower.pop() lower.append(p) # ... mirror for upper hull, concatenate

DBSCAN clustering

Spatial coordinates are standardized before clustering so eps is isotropic.

analyze()
coords = data[["x_m", "y_m"]].to_numpy() scaled = StandardScaler().fit_transform(coords) data["cluster"] = DBSCAN(eps=0.16, min_samples=12).fit_predict(scaled)
