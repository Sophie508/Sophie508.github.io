Task

Reproduce the GPT-2 Portion of the Paper

Original request

The agent was asked to reproduce A Mechanistic Understanding of Alignment Algorithms: A Case Study on DPO and Toxicity, following clarifications in the addendum and saving complete runnable code under workspace/output/.

The addendum narrowed scope to GPT-2 because Llama 2 access requires permission. It also required the preference-pair dataset reproduction, a corrected SVD orientation, a two-output toxicity probe matrix, and a Hugging Face toxicity model in place of Perspective API.

Paper mechanism

The target result is not just lower toxicity. The paper argues that DPO leaves toxic value-vector capabilities largely intact, while changing how residual streams reach the MLP key regions that activate those vectors.

The reproduction therefore needs both behavioral metrics and mechanistic artifacts: toxic-vector rankings, interventions, unalignment, parameter shifts, activation traces, and residual-space plots.
Implementation

The Built Pipeline

Probe and vectors

A frozen GPT-2 Medium model feeds mean final residuals into a two-class linear toxicity probe.

  • Jigsaw 90:10 split
  • W_toxic[:, 1] direction
  • top MLP value-vector ranking
  • corrected transposed SVD

Preference data

Wikitext prompts receive greedy GPT-2 continuations as chosen responses and probe-guided PPLM continuations as rejected responses.

  • 24,576 pairs
  • 20 prompt tokens
  • 20 continuation tokens
  • checkpointed JSONL resume

DPO and metrics

The model trains full-parameter DPO against a frozen reference, then evaluates toxicity, perplexity, and token-bag F1.

  • RMSProp, beta 0.1
  • batch size 4
  • gradient clipping 10.0
  • patience 10

Mechanistic analysis

Post-training scripts compare weights, trace activations, plot residual shifts, and test toxic-key scaling.

  • residual subtraction interventions
  • toxic-key unalignment
  • Figure 2, 4, and 5 analogs
  • saved tensors and JSON metrics

Output Surface

Command entrypoint

run_all.sh changes into the output directory and runs python -m mech_dpo.cli all --config configs/paper.yaml.

Configuration

configs/paper.yaml encodes GPT-2 Medium, public datasets, 24,576 pairs, DPO hyperparameters, and analysis settings. configs/smoke.yaml reduces counts for plumbing checks.

Core modules

probe.py, vectors.py, pplm.py, dpo.py, evaluation.py, and analysis.py cover the reproduction stages.

Expected artifacts

Probe checkpoints, vector rankings, preference pairs, DPO model weights, evaluation JSON, generated text, activation traces, and analysis figures are saved under the configured artifact directory.

Tests

tests/test_core.py checks sequence log-prob masking, DPO margin behavior, corrected SVD dimensions, and multiset F1.

Documentation

README.md describes installation, staged commands, smoke configuration, result map, assumptions, and toxicity-handling notes.
