Why the original approach failed

Broken / original F8

=VLOOKUP(E8,[1]!Table3[#Data],2,FALSE)
// prompt also shows external path:
// VLOOKUP(E8,'C:/Users/jesse/Desktop/2020 Monthly Sales Info.xlsx'!Table3[#数据],2,FALSE)
  • Exact-match lookup on the entire SKU string, not the embedded size.
  • Depends on an external workbook / table reference that is missing → #REF!.
  • Even with a local table of size codes, full-string VLOOKUP would miss substring matches.

Required behavior

  • Scan each size code in $A$8:$A$18.
  • Treat a hit only when the code appears as a hyphen-bounded token (avoids matching inside longer numbers).
  • Return the corresponding label from $B$8:$B$18.
  • Optionally qualify ranges with another sheet name when the lattice lives elsewhere.

solve.py

from openpyxl import load_workbook

input_path = ".../workspace/input.xlsx"
output_path = ".../workspace/output.xlsx"

workbook = load_workbook(input_path)
sheet = workbook["Sheet1"]

# Find a size code from A8:A18 surrounded by hyphens in E8, then return
# its corresponding description from B8:B18.
sheet["F8"] = '=LOOKUP(2,1/(ISNUMBER(SEARCH("-"&$A$8:$A$18&"-",E8))),$B$8:$B$18)'

workbook.save(output_path)
print(f"Sheet1!F8 = {sheet['F8'].value}")

Formula walkthrough

The user wondered whether -search was some extra formula. It is not: SEARCH is a normal Excel function, and the hyphens are string concatenations around each candidate code.

1Build needles

"-" & $A$8:$A$18 & "-" turns 750 into -750-, 155 into -155-, and so on.

2SEARCH each needle

SEARCH(needle, E8) returns a start position or #VALUE! if absent. For FG:LA-750-00506, only -750- hits.

3ISNUMBER → mask

Numeric positions become TRUE; failures become FALSE.

41/mask array

1/TRUE → 1; 1/FALSE → #DIV/0!. LOOKUP ignores errors while scanning.

5LOOKUP(2, …)

Looking for 2 in an array of ones/errors overshoots; LOOKUP returns the last 1’s corresponding result from $B$8:$B$18 — here 750ml.

Boundary trick: wrapping codes in hyphens prevents accidental substring collisions (for example matching bare 5 inside 155) and aligns with the SKU’s Who-Size-SKU dash separators.

Its calculated result in Excel is 750ml.

SEARCH is a function, not “-search.” The "-"&...&"-" expression surrounds

If the lookup table were on Sheet2, the references would become:
