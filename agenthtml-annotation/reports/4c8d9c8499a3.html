Formula anatomy

Click a clause to see what it contributes · interactive breakdown

=LOOKUP(2,1/(ISNUMBER(SEARCH("-"&$A$8:$A$18&"-",E8))),$B$8:$B$18)

SEARCH with hyphen guards

SEARCH("-"&$A$8:$A$18&"-",E8) does not call a fictional “-search” formula. SEARCH is the Excel function; the hyphens are ordinary text concatenated around each candidate code.

For code 750, the pattern becomes -750-, which matches inside FG:LA-750-00506 without false-hitting a neighboring number.

1. BuildWrap each A-code as -155-, -750-, …
2. ProbeSEARCH each pattern against E8
3. CastISNUMBER → TRUE/FALSE; 1/x keeps hits as 1, misses as #DIV/0!
4. LookLOOKUP(2, mask) ignores errors, returns last 1
5. MapSame position in B8:B18 yields 750ml

from openpyxl import load_workbook

workbook = load_workbook(input_path)
sheet = workbook["Sheet1"]

# Find a size code from A8:A18 surrounded by hyphens in E8,
# then return its corresponding description from B8:B18.
sheet["F8"] = '=LOOKUP(2,1/(ISNUMBER(SEARCH("-"&$A$8:$A$18&"-",E8))),$B$8:$B$18)'

workbook.save(output_path)
print(f"Sheet1!F8 = {sheet['F8'].value}")

Answers to the human questions

Beyond filling the cell · the agent closed the conceptual loop

Is “-search” an extra formula?

No. The expression is plain string concatenation feeding the built-in SEARCH function. "-"&$A$8:$A$18&"-" manufactures patterns like -155- and -750- so a size code only matches when flanked by hyphens.

Why does LOOKUP(2, 1/(…)) work as a filter?

ISNUMBER(SEARCH(...)) produces TRUE for the matching row. Dividing 1 by that array keeps 1 for hits and #DIV/0! for misses. LOOKUP binary-searches for 2, never finds it, and returns the last numeric value less than 2 — i.e. the final successful 1 — then pairs that position with the return vector $B$8:$B$18.

Why did the original VLOOKUP fail?

It required an exact match on the entire SKU and pointed at an external structured table ([1]!Table3[#Data] / path on another machine). The size token is only a substring of E8, so exact lookup cannot see it even if the workbook link were healthy.

How do I point at another worksheet?

Qualify every range: Sheet2!$A$8:$A$18 and Sheet2!$B$8:$B$18. The SEARCH / LOOKUP structure stays identical — only the sheet scope changes.
