02 Method

The agent defines intraday volatility as the daily percentage range — the spread between each session's high and low, normalized by the opening price. This avoids scale distortion: a 100-point swing means something very different for the Nikkei (≈38,000) than for the Nifty (≈22,000).

intraday_volatility = (High − Low) / Open × 100

Six Asia-region indices were identified from the exchange metadata table (Hong Kong, Shanghai, Tokyo, Shenzhen, Mumbai, Taipei). Trade records since 2020-01-01 were filtered, grouped by index, and averaged. All 0 unparsed dates confirmed a clean parse.

03 The Date Problem

The Date column in the trade table mixes three incompatible string formats across decades of records. The agent stacked three try_strptime calls inside a COALESCE to catch them all — and verified zero rows fell through.
