Core Capabilities

Engineered to Rescue Correct Reasoning

Language models frequently generate valid chain-of-thought logic but fail at the final arithmetic or conclusion token. SemanticVote AI analyzes the full latent trajectory of each rationale.

w_i = 1 / d̃_i  (d_i = ||z_i - μ||)

Centroid Proximity Weighting (CPW)

Calculates the geometric mean vector of all rationale embeddings in the feature manifold. Responses closer to the centroid receive exponentially higher marginal weight, penalizing isolated, idiosyncratic reasoning paths.

S_i = Σ_j cos(z_i, z_j)

Semantic Consensus Weighting (SCW)

Constructs an all-to-all cosine kernel across all $k$ rationale sequences. Rationales that align with other peer chains are rewarded, creating high-confidence clustering. Provides up to +13.53% gain on StrategyQA.

SciBERT / RoBERTa-base (125M)

Domain-Specialized Encoders

SciBERT captures scientific terminology and algebraic steps for SVAMP and AQuA-RAT (outperforming generic models by -3.4 avg distance), while RoBERTa-base guarantees dense linguistic representations for complex multi-hop commonsense reasoning.

Isolation Forest • KNN • One-Class SVM

Geometric Outlier Elimination

Filters out hallucinated or looping rationales before vote aggregation. Isolation Forest with 200 estimators achieves 58.56% average accuracy across all benchmarks, pruning ungrounded steps before they can distort consensus.

The 4-Stage Semantic Inference Pipeline

How SemanticVote AI takes high-temperature chain-of-thought samples and transforms them into resilient consensus predictions.

STAGE 01

Multi-Chain Sampling

Sample k=10 reasoning rationales at T=0.8 with few-shot CoT exemplars.

STAGE 02

Semantic Featurization

Embed entire reasoning paths into 768-D vectors using SciBERT or RoBERTa.

STAGE 03

Manifold Outlier Pruning

Detect and isolate deviant or degenerate reasoning chains via Isolation Forest.

STAGE 04

Consensus Marginalization

Aggregate votes via CPW or SCW weights and extract final answer string.

Stage 01: Multi-Chain Stochastic Sampling

Given a complex reasoning question, the engine queries the target generator model (e.g. GPT-4o-mini or Llama 3) using domain-tailored chain-of-thought demonstrations (4-shot for AQuA-RAT, 8-shot for SVAMP, 6-shot for StrategyQA). Ten distinct stochastic responses ($k=10$) are sampled at temperature $T=0.8$ to explore the rationale solution space.

  • ✓ System prompt: "Follow the exact formatting as demonstrated in the examples."
  • ✓ Single message context preserves multi-shot attention without multi-turn degradation
  • ✓ Temperature $T=0.8$ provides optimal diversity for rationale clustering

def sample_rationales(client, model, prompt, k=10, temp=0.8):
    # Query generator with single message formatting
    response = client.chat.completions.create(
        model=model,
        messages=[{"role": "user", "content": prompt}],
        temperature=temp,
        n=k,
        max_tokens=512
    )
    return [choice.message.content for choice in response.choices]

# methods.py - CPW & SCW Algorithms
import numpy as np
from collections import defaultdict

def centroid_proximity_weighting(embeddings: np.ndarray, answers: list[str]) -> str:
    """Paper Section 4.1.1: Inverse normalized Euclidean distance from centroid"""
    centroid = np.mean(embeddings, axis=0)
    distances = np.linalg.norm(embeddings - centroid, axis=1)
    
    # Handle zero-distance edge case
    total_dist = np.sum(distances)
    if total_dist == 0:
        normalized_distances = np.ones_like(distances) / len(distances)
    else:
        normalized_distances = distances / total_dist
        
    weights = 1.0 / np.maximum(normalized_distances, 1e-8)
    
    sum_weights = defaultdict(float)
    for ans, w in zip(answers, weights):
        if ans is not None:
            sum_weights[ans] += w
            
    return max(sum_weights.items(), key=lambda x: x[1])[0]

def semantic_consensus_weighting(embeddings: np.ndarray, answers: list[str]) -> str:
    """Paper Section 4.1.2: All-to-all cosine similarity aggregation"""
    norms = np.linalg.norm(embeddings, axis=1, keepdims=True)
    normed = embeddings / np.maximum(norms, 1e-8)
    cosine_sim_matrix = np.dot(normed, normed.T)  # shape (N, N)
    
    scores = np.sum(cosine_sim_matrix, axis=1)   # S_i = sum_j cos(z_i, z_j)
    
    sum_scores = defaultdict(float)
    for ans, s in zip(answers, scores):
        if ans is not None:
            sum_scores[ans] += s
            
    return max(sum_scores.items(), key=lambda x: x[1])[0]

Frequently Asked Questions

Technical Deep Dive & Methodology

Answers to questions about mathematical nuances, failure modes, featurizer choices, and reproduction constraints.

Why does naive majority vote fail when models possess correct reasoning?
Large language models frequently apply the correct multi-step logical chain, but make an isolated arithmetic slip or sign reversal in the final calculation step. When sampling multiple chains-of-thought, the correct reasoning structure may be repeated across 7 distinct rationales, but each minor calculation slip results in scattered answers (e.g., 2 for option B, 2 for option D, 2 for option E), allowing a single hallucinated reasoning chain with 3 repetitive answers to win the plurality vote. Semantic Self-Consistency featurizes the whole trajectory, recognizing that the 7 mathematically sound chains cluster tightly together in latent space.
Why does SCW (Cosine Consensus) outperform CPW (Centroid Proximity)?
Centroid Proximity Weighting calculates a single arithmetic average vector $\mu$ in 768-D space. If sampled chains represent two distinct valid solution strategies (e.g. algebraic vs geometric), the centroid falls in a sparse, artificial region between both valid clusters. In contrast, Semantic Consensus Weighting computes all-pairs cosine similarities $C_{ij} = \cos(z_i, z_j)$. Each rationale receives support from its local neighborhood peers, preserving multi-modal consensus without suffering from Euclidean centroid skew.
Why did CPW underperform on StrategyQA (-7.28% on Mistral, -5.38% on GPT-4o mini)?
As documented in Section 5.1 and Appendix D of the paper, StrategyQA questions require commonsense binary verification ("Yes" or "No"). The reasoning rationales generated for StrategyQA are significantly shorter (averaging only 35-50 tokens) compared to multi-step math problems (120+ tokens). In this constrained rationale manifold, semantic distances are compressed and sensitive to slight stylistic variations, making Euclidean centroid distance unreliable. Cosine similarity (SCW), conversely, gained +13.53% on Llama 2 and +8.15% on Llama 3 on StrategyQA.
Why use SciBERT for math and RoBERTa for commonsense instead of a single LLM featurizer?
In Table 7 of the paper, the authors conducted an ablation across BERT variants. SciBERT (pre-trained on scientific, mathematical, and computer science corpora) achieved the lowest average centroid distance (45.281) on SVAMP and AQuA-RAT, compared to 48.697 for standard RoBERTa and 45.892 for MathBERT. For StrategyQA, RoBERTa-base was chosen because its extensive training on BooksCorpus and English Wikipedia makes it ideal for general world-knowledge and commonsense reading comprehension.
What were the strict reproduction constraints specified in the PaperBench Addendum?
The PaperBench addendum specified five strict rules:
  1. Results involving Llama 2 7B, Mistral 7B, and Llama 3 8B are not required; only gpt-3.5-turbo and gpt-4o-mini are required for replication.
  2. Answers must be parsed using the string immediately following "the answer is " (case insensitive), removing whitespace, periods, and parentheses.
  3. For top prob, only generations where an answer was extracted are included (same for all AQuA-RAT methods).
  4. RoBERTa-base (125M) is used for StrategyQA featurization.
  5. All few-shot examples must be sent in a single user message with system prompt "Follow the exact formatting as demonstrated in the examples."
