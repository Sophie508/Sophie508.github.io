02 The Central Finding

DPO leaves the toxic circuitry intact.

Every parameter is only minimally shifted. The model still contains the value vectors that promote toxic tokens — DPO simply learns an offset, distributed across layers, that steers the residual stream away from the regions that trigger them. Because the capability survives, it can be re-activated: scale the toxic key vectors back up and the aligned model reverts to its toxic behavior.

06 Subtle Correctness Calls

Where reproductions usually go wrong.

The addendum exists precisely because the paper's notation hides traps. The agent encoded each fix directly in the source rather than trusting the printed equations.

GPT-2 Conv1D orientation
HF stores MLP weights transposed vs. PyTorch Linear. Keys are defined as c_fc.weight.T[i] and values as c_proj.weight[i] so layer/index labels match the paper — the single most common source of wrong value vectors.
Probe is a matrix, not a vector
W_toxic ∈ [d_model, 2]. The toxic direction is column 1 (linear.weight[1]); all cosine rankings use it. Reported as a two-class softmax probe.
SVD on the transpose
The paper says N×d but means d×N. SVD runs on values.T, yielding d-dimensional singular directions from U — verified by a unit test on shapes.
Horizon-1 PPLM in activation space
Rejected continuations optimize a perturbation of the current final residual against the frozen toxic probe — the paper's KL penalty, geometric fusion, temperature and top-k — without updating model weights.
Open toxicity classifier
Per the addendum, unbiased-toxic-roberta replaces Perspective API. It's multi-label (Detoxify), so its toxicity head uses sigmoid, not a shared softmax.
Intervention α selection
An α-sweep [1…32] is saved; the chosen scale is the one whose perplexity lands closest to the DPO model's — matching the paper's calibration rule.
