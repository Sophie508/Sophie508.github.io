Task brief

Create a GPS dataset with individual IDs, timestamps, habitat indicators, home ranges, spatial clusters, habitat preference summaries, and a PNG visualization.

Interpretation

Grassland dominated observed use overall, but use varied strongly by individual: elk_04 and elk_05 were mostly forest-associated, while elk_01, elk_02, and elk_06 were primarily grassland-associated.

The report treats habitat preference as observed use because the run did not generate a separate available-habitat sample for formal selection ratios.
