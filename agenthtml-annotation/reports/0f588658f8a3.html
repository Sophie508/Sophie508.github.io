Why this measure

Three deliberate modeling choices

The agent made the volatility definition explicit rather than defaulting to raw point moves — a decision that changes the ranking.

📐

Percentage range, not points

Raw High − Low in index points favors high-value indexes. Dividing by Open yields a comparable, scale-invariant daily range across markets.

🌏

Six Asia-region indexes

Filtered to Hang Seng, Shanghai Composite, Nikkei 225, Shenzhen Component, Nifty 50, and Taiwan Weighted — mapped from exchange metadata to price-table tickers.

🗓️

Since-2020 window

Restricted to dt >= 2020-01-01 with Open > 0 and non-null High/Low, guarding the ratio against bad rows.

Behind the run

Four sandbox hurdles, all worked around

The environment fought back before the query ran. The agent kept the databases read-only and iterated on how to ship a Python script into a locked-down shell.

shell Heredocs are blocked +
The first attempt piped a script via python - <<'PY'. The shell refused it, so the agent abandoned heredocs for direct invocation. 
zsh:1: can't create temp file for here document: operation not permitted
quoting zsh parse errors on nested quotes +
Cramming the SQL into a single python -c '...' with escaped inner quotes tripped the parser repeatedly. 
zsh:1: parse error near `)'
runtime No TextEncoder / btoa in exec host +
To dodge quoting, the agent tried base64-encoding the script in JavaScript. The exec runtime lacked browser globals. 
ReferenceError: TextEncoder is not defined
ReferenceError: btoa is not defined
fix JSON-stringify the script → success +
The winning move: pass the multi-line Python via python -c  + JSON.stringify(script), letting the JS layer handle escaping cleanly. The DuckDB query then ran in 0.4s.
