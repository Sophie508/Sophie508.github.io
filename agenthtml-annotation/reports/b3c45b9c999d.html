Analysis method

Release order first. Stars second.

FILTER / 01

Keep NPM releases

Read packageinfo, parse VersionInfo, and retain rows where IsRelease is true.

REDUCE / 02

Select the latest

For every package name, choose the version with the greatest registry Ordinal.

RANK / 03

Map and sort

Parse stars from project descriptions, join on latest package versions, reduce duplicate mappings to each package’s highest-star project, then sort descending.
