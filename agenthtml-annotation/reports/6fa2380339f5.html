The task

Two KL divergences, one distribution

Confidence of an LLM token prediction is measured by KL divergence between the model distribution P and the uniform distribution U. The goal is a single P that hits a target of 10.0 on both directions.

Forward KL — target 10.0
KL(P‖U) = Σ P(i)·log( P(i) / U(i) )
Backward KL — target 10.0
KL(U‖P) = Σ U(i)·log( U(i) / P(i) )
  • forward KL(P‖U) = 10.0, tolerance ±0.001
  • backward KL(U‖P) = 10.0, tolerance ±0.001
  • vocabulary size n = 150,000
  • P must be a valid probability distribution (non-negative, sums to 1)
  • save to /app/dist.npy as a NumPy array  (numpy + scipy available)
