Method

From releases to stars

The calculation joins two stores indirectly: SQLite supplies package release facts; DuckDB supplies package-to-project relations and star-bearing project descriptions.

Select latest releases

Filter packageinfo to System = NPM and IsRelease = true, then retain the version with the greatest VersionInfo.Ordinal for every package name.

Recover popularity

Parse GitHub project names and star counts from project_info.Project_Information. Stars are embedded in descriptive text rather than stored as a numeric field.

Map, dedupe, rank

Match the latest name/version pair through project_packageversion. For duplicate mappings, keep that package’s highest-star project, then sort descending and take five.
