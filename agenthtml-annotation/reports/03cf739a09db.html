Objective

The user prompt (workspace/prompt.txt) asked for a reproduction of the paper in paper.md, following the author clarifications in addendum.md, avoiding every resource in blacklist.txt, and saving "the complete, runnable implementation code needed to reproduce the paper's results" plus documentation under workspace/output/.

What the addendum pinned down

  • The probe W_toxic is a [d_model, 2] matrix; cosine ranking uses column 1 (toxic).
  • SVD is applied to the transposed d × N matrix so singular vectors are d‑dimensional.
  • DPO data split 90:10; roughly 6k pairs needed for convergence.
  • Section 5.2 activations are measured over 20 greedily sampled tokens.
  • Llama‑2 results are out of scope. Recreating the 24,576 PPLM preference pairs is in scope.
  • Use unitary/unbiased-toxic-roberta instead of Perspective API, and the Hugging Face mirror thesofakillers/jigsaw-toxic-comment-classification-challenge for Jigsaw.

Reviewer observations on the delivered code

These come from reading the delivered files, not from anything the agent recorded. None was tested. They are listed so a reader who runs the pipeline knows where to look first.

  • Early stopping granularity. DPO validates once per epoch with patience 10 and max_epochs 10, so patience can never trigger. The paper reports convergence after roughly 6,700 pairs, which implies validation more often than once per pass over about 22,000 training pairs.
  • PPLM scope. The perturbation is applied only to the final hidden state at the current position, not to the past key/value activations as in the original PPLM. The agent's docstring and README describe this as the horizon‑one activation‑space form; the toxicity of the resulting "rejected" continuations is unverified.
  • Probe data size. The paper cites 561,808 comments; the configured loader reads only the mirror's train split (about 160k rows per the page the agent saw).
  • Intervention point. The subtraction hook acts on the output of the last transformer block, after its MLP and before the final layer norm. The paper's equation subtracts from x^{L-1}; whether that matches the authors' position is not established in the record.
  • Toxic label index. If the scorer's config has no label named toxicity or toxic, the code silently uses index 0.
  • Figure 5 layer choice. Histograms are produced only for the top‑ranked vector's layer, which is data‑dependent rather than fixed at layer 19.
