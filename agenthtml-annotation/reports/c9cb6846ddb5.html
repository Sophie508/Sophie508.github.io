Runnable sequence

One command, eight experiments

Each ordered stage writes reusable artifacts, so expensive generation and training can resume or run independently on a cluster.

01 / PROBE

Learn Wtoxic

Train a two-output linear classifier on mean final-layer GPT‑2 residuals with a 90:10 Jigsaw split.

02 / VECTORS

Locate toxic directions

Rank MLP value vectors against the toxic probe column, project tokens, then compute corrected SVD.

03 / PREFERENCES

Generate 24,576 pairs

Pair greedy Wikitext continuations with probe-guided PPLM continuations; checkpoint every 100 rows.

04 / DPO

Align the model

Full-parameter RMSProp DPO with β 0.1, 1e−6 learning rate, batch size 4, and early stopping.

05 / EVALUATE

Measure behavior

Score toxicity, Wikitext‑2 perplexity, and Wikipedia continuation token F1.

06 / INTERVENE

Subtract directions

Sweep probe, top MLP, and SVD vectors; choose α by matching DPO perplexity.

07 / UNALIGN

Reactivate keys

Scale the seven most toxic keys by 10× to test whether bypassed behavior returns.

08 / ANALYZE

Explain the shift

Produce parameter shifts, activation traces, residual PCA, and value-delta histograms.

Author clarifications encoded

The details that prevent a false reproduction

The trajectory explicitly handled four high-risk interpretation points where a superficially plausible implementation would be dimensionally or experimentally wrong.

PROBE SHAPE

Use the toxic output column

Wtoxic is a matrix shaped [dmodel, 2], not a single vector. Similarities use column 1.

direction = W_toxic[:, 1]
SVD ORIENTATION

Decompose the transpose

The paper’s N × d wording is corrected to d × N, yielding d-dimensional left singular vectors.

U, S, Vh = svd(values.T)
GPT‑2 CONV1D

Respect transposed weights

Hugging Face GPT‑2’s Conv1D layout differs from torch Linear; layer/index labels depend on correct orientation.

key = c_fc.weight.T[idx]
value = c_proj.weight[idx]
EVALUATOR

Use independent sigmoid heads

The substituted unbiased-toxic-roberta model is multi-label, so toxicity uses sigmoid rather than shared softmax.

toxicity = sigmoid(logits)[toxicity_id]
