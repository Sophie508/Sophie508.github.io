How the answer was computed

The workflow joined the two sources in Python by carrying the catalog’s track ID into the sales query.

1

Inspect both schemas

SQLite contains track identity and metadata; DuckDB contains country, store, units, and USD revenue.

2

Resolve the exact recording

An exact title + artist lookup returned one row: track_id = 4122.

3

Aggregate and rank stores

Revenue was summed across all sales rows for that ID, grouped by store, then sorted descending.

import sqlite3, duckdb

tracks = sqlite3.connect("data/tracks.db")
ids = [row[0] for row in tracks.execute("""
  SELECT track_id FROM tracks
  WHERE title = 'Street Hype'
    AND artist = 'Brucqe Maginnis'
""")]

sales = duckdb.connect("data/sales.duckdb", read_only=True)
# ids resolved to [4122]
result = sales.execute("""
  SELECT store, SUM(revenue_usd) AS total_rev
  FROM sales WHERE track_id = 4122
  GROUP BY store ORDER BY total_rev DESC
""").fetchall()
