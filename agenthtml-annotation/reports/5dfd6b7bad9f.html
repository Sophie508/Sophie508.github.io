The Task

Column A holds //-delimited display names such as HONEG BUCKET FLOHAWK//PUYALLUP//98373//103137391INACT//US. From each string, extract the site code — the segment sitting just before the trailing //US — into column B.

Requirement: write Python using openpyxl to load input.xlsx, fill the answer cells B2:B7 with correct values/formulas, save to output.xlsx, and print the results.

The Solution

The formula (applied to each row):

=LET(
  code, TEXTBEFORE(TEXTAFTER(A2,"//",-2),"//"),
  IFERROR(VALUE(code), code)
)

TEXTAFTER(…,"//",-2) takes everything after the 2nd-from-last delimiter; TEXTBEFORE(…,"//") then trims the trailing US. VALUE coerces pure-numeric codes, and IFERROR keeps alphanumeric ones as text.

solve.py

from pathlib import Path
from openpyxl import load_workbook

INPUT  = Path(".../workspace/input.xlsx")
OUTPUT = Path(".../workspace/output.xlsx")

workbook = load_workbook(INPUT)
sheet = workbook["Sheet1"]

# Extract the text between the last two // delimiters. Numeric codes are
# converted to numbers; alphanumeric codes remain text.
for row in range(2, 8):
    sheet.cell(row, 2).value = (
        f'=LET(code,TEXTBEFORE(TEXTAFTER(A{row},"//",-2),"//"),'
        f'IFERROR(VALUE(code),code))'
    )

workbook.calculation.fullCalcOnLoad = True
workbook.calculation.forceFullCalc  = True
workbook.calculation.calcMode = "auto"
workbook.save(OUTPUT)

for row in range(2, 8):
    print(f"B{row}={sheet.cell(row, 2).value}")
